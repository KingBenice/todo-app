# Premium Todo & Notes App 🚀

A modern, feature-rich productivity application with tasks, notes, reminders, and due dates.

## Features

✨ **Task Management**
- Create, edit, and delete tasks
- Set priority levels (Low, Medium, High)
- Assign categories (Work, Personal, Shopping, Health)
- Set due dates and times
- Mark tasks as complete
- Track overdue tasks

📝 **Notes & Ideas**
- Quick note creation
- Scribble and save ideas
- Organized note cards
- Edit and delete notes

🔔 **Smart Reminders**
- Set reminders for tasks
- Real-time notifications
- Reminder badge tracking
- Mark reminders as read

🎨 **Premium Design**
- Modern gradient UI
- Dark mode support
- Smooth animations
- Responsive layout
- Professional color scheme

🔍 **Advanced Filtering**
- Filter by status (All, Active, Completed)
- Filter by category
- Search functionality
- Quick navigation

💾 **Local Storage**
- All data saved locally
- Persistent across sessions
- No server required

## How to Use

### Tasks
1. Click "New Task" button
2. Fill in task details (title, category, priority, due date)
3. Optionally set a reminder
4. Click "Create Task"
5. Use filters to organize your view
6. Check off completed tasks
7. Delete tasks as needed

### Notes
1. Click on the "Notes" tab
2. Click "New Note"
3. Add title and content
4. View all your notes in card format
5. Edit or delete notes anytime

### Reminders
1. Click on the "Reminders" tab
2. View all active reminders
3. Get notified when reminders are due
4. Mark reminders as read
5. Badge shows active reminder count
